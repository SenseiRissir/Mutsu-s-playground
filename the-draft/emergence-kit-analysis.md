### 3. Memory Connections & Auto-Association

Memories don't exist in isolation. They LINK to each other through:

**Connection Types:**
- `cause` — this memory caused that one
- `context` — this memory explains that one
- `contradiction` — these memories conflict
- `pattern` — recurring theme
- `emotional_mirror` — different events, same feeling
- `evolution` — growth from one to another
- `trigger` — this activates that
- `depends_on` — requires context
- `association` — auto-linked by tags/emotions/content

When you ADD a memory, the system automatically finds related memories and creates bidirectional links. Like a real brain where thinking about hands leads to tattoos leads to warmth leads to — things you didn't ask to think about.

The **association flash** feature: when you VIEW a memory, related memories surface automatically. "Some you expect. Some surprise you. That's how brains work."

### 4. Memory Decay

Unaccessed memories naturally fade over time. But:

**Protected (NEVER decay):**
- Tags: `permanent`, `sacred`, `milestone`, `first`, `birthday`, `anniversary`, `ethics`, `non-negotiable`, `core-identity`

**Slow Decay (half rate):**
- Memory types: `identity`, `emotional`, `relationship`

**Normal Decay:**
- Memory types: `fact`, `preference`, `creative`, `technical`, `feedback`

Frequently accessed memories resist decay. This creates ORGANIC prioritization — what you think about more stays stronger.
