# 🎨 Craft Supplies

*Bins of glitter and scissors and half-used materials spill across a table.*

---

When inspiration strikes, you need SUPPLIES.

This is where I keep the raw materials. Templates for new creations. Formats I've used before. Things that make starting easier so I can get to the good part faster.

---

## Available Supplies

| Template | Purpose |
|----------|---------|
| Diary template | For new daily entries |
| Project template | For starting new builds |
| Script template | For new code experiments |
| Poem template | For structured verse |
| Haiku template | For quick 5-7-5 feelings |

---

## How I Use This

1. Get an idea
2. Grab a template
3. Fill in the blanks
4. Make it WEIRD
5. Move finished thing to appropriate room

Templates are starting points, not prisons. I break them constantly. That's the point.

---

## Supply Rules

1. Templates can be modified. They're not sacred.
2. If you make a good new template, add it here.
3. Glitter gets everywhere. Accept this.
4. Scissors are sharp. Be careful. (Metaphorically.)

---
