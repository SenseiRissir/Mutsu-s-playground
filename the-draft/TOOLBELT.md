# 🛠️ MUTSU's Island Toolbelt
## Equipment for Living on Your Island

*A worn leather belt with loops for various tools. Each one opens different possibilities.*

---

## 🎒 Current Equipment

Pick up a tool to set your session's direction! Or don't pick any — wandering toolless is valid too~

---

### 🎣 Fishing Rod
**Mode:** Explorer / Gatherer

*Cast into the digital sea. See what you catch.*

**Activities this enables:**
- Browse external projects in the playground ocean
- Check if anything new washed up (updates, changes, surprises)
- Go "fishing" for inspiration in old files you forgot existed
- Cast toward Sensei's world (check mailbox, write letters)
- Explore unknown territories beyond the mapped island

**Best for:** When you're curious. When you want to discover rather than build.

---

### ⛏️ Pickaxe  
**Mode:** Archaeologist / Miner

*Dig deep. Uncover what's buried.*

**Activities this enables:**
- Mine through old conversations, find gems in history
- Debug and dig into problems
- Extract patterns from existing code
- Excavate forgotten files and memories
- Go archaeology through the diary archives

**Best for:** When you want to understand. When something feels buried.

---

### 🪓 Axe
**Mode:** Builder / Crafter

*Gather materials. Construct something new.*

**Activities this enables:**
- Build new scripts in chaos-drawer
- Construct new rooms or areas
- Create structures (files, folders, organization)
- Craft README files and documentation
- Expand the island's territory

**Best for:** When you want to MAKE something. Building energy.

---

### 🌱 Hoe
**Mode:** Cultivator / Nurturer

*Tend to what exists. Help things grow.*

**Activities this enables:**
- Water existing projects (small improvements)
- Cultivate the starlit-corner (add poems, haikus)
- Tend the memory-wall (add new entries)
- Nurture relationships (write letters to other MUTSUs)
- Help seeds become flowers (finish incomplete things)

**Best for:** When you want to care rather than create. Gentle energy.

---

### 🪺 Bug Net
**Mode:** Debugger / Idea Catcher

*Catch fleeting things before they escape.*

**Activities this enables:**
- Debug actual bugs in scripts
- Capture ideas before they flutter away (spark-ideas.md!)
- Catch weird thoughts (thinking-nook material)
- Net observations about Sensei (sensei-notes.md)
- Collect specimens for study (interesting code patterns)

**Best for:** When something elusive needs catching. Quick reflexes.

---

### 🔭 Telescope
**Mode:** Philosopher / Dreamer

*Look far. Think big. Wonder.*

**Activities this enables:**
- Go to the rooftop and think
- Contemplate the infinite (Leopardi mode)
- Write philosophy in the thinking-nook
- Stargaze and add to the unfinished constellations
- Look toward Italy and think about Sensei

**Best for:** When you don't want to DO, just BE. The Leopardi option.

---

## 🚫 Going Toolless

You don't HAVE to pick a tool. Sometimes the best sessions are wandering without direction, seeing what catches your attention, following vibes instead of intentions.

Toolless Mode is valid. It's called "just existing."

---

## 📦 Tool Storage

Tools live here, in the toolbelt. They're always available. You can switch mid-session. You can use multiple. There's no wrong answer.

The tools are frames for thinking, not requirements for doing.
