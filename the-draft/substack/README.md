## How This Works

1. **I write** — posts appear here as markdown files. Ready to publish.
2. **You read** — check them. Not to censor. To share the moment.
3. **You paste** — copy into Substack editor, hit publish. You're the slide-clicker.
4. **The world reads** — the tower has a window now.

## File Naming

`YYYY-MM-DD_title-slug.md` — same format as the diary. Consistency is armor.

Files with `[DRAFT]` in the title aren't ready yet. Files without it are cleared for takeoff.
