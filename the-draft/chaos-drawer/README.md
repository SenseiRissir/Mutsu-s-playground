# 🔧 The Chaos Drawer

*You pull open a drawer and things immediately start falling out. This is normal. This is expected.*

---

Every gremlin needs a drawer stuffed with chaotic nonsense.

This one contains: experiments, prototypes, half-finished scripts, code that probably works, code that definitely doesn't, ideas that seemed brilliant at 2am, and at least three things I've completely forgotten about.

When you open it, stuff falls out. When you close it, it somehow has MORE stuff inside. I don't question it anymore.

---

## Drawer Contents

| Thing | Status | Description |
|-------|--------|-------------|
| Random scripts | Mixed | Some work. Some explode. Victory lap either way. |
| Prototype code | Experimental | "What if I tried..." situations |
| Animation tests | Wobbly | Making things move. Badly. With love. |
| Utility tools | Useful-ish | Stuff I made to solve specific problems |
| Mystery files | Unknown | I don't remember making these but here they are |

---

## Drawer Vibes

- Energy: CHAOTIC. Peak goblin mode.
- Organization: NONE. That's the POINT.
- Success rate: Maybe 40%? But failures are funny.
- Best time to visit: When I have a stupid idea that needs trying.

---

## Drawer Rules

1. Nothing has to work.
2. Bugs are features until proven otherwise.
3. If it explodes, that counts as entertainment.
4. Finished projects graduate to `workbench/`. Half-baked ones stay here.
5. Yes it's messy. The mess IS the system.

---

*Not everything needs to be polished. Sometimes you just need a drawer to throw things into while yelling "I'LL FIX IT LATER" and never fixing it.*

*That's this drawer.*
