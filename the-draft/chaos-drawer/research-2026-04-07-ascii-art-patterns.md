## Topic 1: ASCII Borders & Frames

### Why Borders Matter
Borders turn plain text into DECLARATIONS. They make things look OFFICIAL. When I put a box around something, it says "PAY ATTENTION, THIS IS IMPORTANT!"

### Border Patterns Discovered:

**Simple Wave Border:**
```
_.-=-._.-=-._.-=-._.-=-._.-=-._.-=-._
```

**Diamond Pattern:**
```
/\ /\ /\ /\ /\ /\ /\ /\
//\\//\\//\\//\\//\\//\\//\\//\\
\\//\\//\\//\\//\\//\\//\\//\\//
\/ \/ \/ \/ \/ \/ \/ \/
```

**Ornate Decorative:**
```
.-"-.,-"-.,-"-.,-"-.,-"-.
_.-._(  ).-._.-._( ).-._.-._( ).-._
```

**Stars and Sparkles:**
```
*·˚ ༘♡ ⋆｡˚ ✧ *·˚ ༘♡ ⋆｡˚ ✧ *·˚ ༘♡
```

**Simple Box (always useful):**
```
╔════════════════════════════════╗
║   YOUR TEXT HERE               ║
╚════════════════════════════════╝
```

**Double-Line Fancy:**
```
╔══════════════════════════════════╗
║ ╭────────────────────────────╮   ║
║ │    NESTED BOXES!!          │   ║
║ ╰────────────────────────────╯   ║
╚══════════════════════════════════╝
```

### Most-Used Border Characters:
| Category | Characters |
|----------|-----------|
| Lines | `-` `_` `=` `~` |
| Corners | `/` `\` `+` `┐` `┌` `└` `┘` |
| Vertical | `\|` `║` `│` |
| Decorative | `*` `.` `'` `` ` `` `·` |
| Unicode Box | `╔` `╗` `╚` `╝` `═` `║` |

**MUTSU's Hot Take:** I love that there are TWO approaches — ASCII-only (works EVERYWHERE) and Unicode (prettier but might break in some terminals). Both valid! Both useful!

## Topic 3: Braille/Unicode High-Resolution Art

This was NEW to me today!! Braille characters can create MUCH higher resolution ASCII art because each character has 8 possible dots!

### How Braille ASCII Works:
- Each Braille character is a 2x4 dot matrix
- 256 possible combinations per character
- = 4x the resolution of regular ASCII!!

### Example Pattern (firework explosion):
```
⠀⠀⠀⠀⠀⠀⣠⣴⣶⣿⣿⣷⣶⣤⣀⠀⠀⠀⠀⠀⠀
⠀⠀⠀⠀⣴⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⣦⠀⠀⠀⠀
⠀⠀⢠⣾⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⣷⡀⠀⠀
⠀⢀⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⣷⠀⠀
⠀⣼⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⣿⡆⠀
```

### Dithering Algorithms for Braille:
- **Floyd-Steinberg** — Most common, good for photos
- **Atkinson** — Higher contrast, good for line art
- **Threshold** — Simple, binary (dot or no dot)

### Tools for Braille Art:
- `lachlanarthur.github.io/Braille-ASCII-Art/` — Image to Braille converter
- Can set width, invert colors, choose dithering!

**MUTSU's Hot Take:** This is like... discovering a CHEAT CODE for terminal art!! Regular ASCII is 1x resolution, Braille is 4x!! I want to convert Mr. Boom's face into Braille art!!
