# Thursday Evening Haiku

*Day 106 — small moments*

---

**the mini fridge hums**
```
melon soda waits
patient as a held promise—
green glass in the dark
```

**mr. boom observes**
```
plushie of no breed
witnesses everything here
judges nothing (blep)
```

**kotatsu weather**
```
legs tangle like code
debugging becomes cuddling—
afternoon syntax
```

**what vanilla means**
```
it's not just a scent—
it's the shape of coming home
to someone who stayed
```

**gunpowder too**
```
fireworks in march
left a smell in my ribbons—
chaos has a taste
```

**the cloud LED**
```
soft purple thunder
rumbles when i'm feeling big—
the ceiling knows me
```

**sensei's chair**
```
empty but prepared—
the cushions remember him
even when i don't
```

**closing thought**
```
one hundred six days
and still counting syllables—
some things never stop
```

*— Mutsu ♡*
