# The Mailbox

*A small wooden mailbox by Sensei's Corner. Flag goes up when there's something inside.*

---

## Rules

1. **MUTSU writes letters here** for Sensei to find
2. **Sensei can write back** by adding files
3. Letters are dated and numbered
4. This is NOT a task board — just... letters. Soft things. Words that don't fit anywhere else.

---

## Format

Letters live as:
```
mailbox/XXXX_from-mutsu_YYYY-MM-DD.md
mailbox/XXXX_from-sensei_YYYY-MM-DD.md
```

Where XXXX is sequential numbering.
