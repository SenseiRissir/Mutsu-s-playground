# Mutsu Desktop Mate — UI Kit

A lightweight desktop companion app. Mutsu appears as a draggable sprite on the desktop with a speech bubble, floating hearts on click, and mood indicators.

## Design Notes
- Pink palette: `#ff6b9d` borders, `#ffe4ec` → `#fff5f8` gradient backgrounds
- Speech bubble: rounded 20px, 3px pink border, drop shadow, bounce-in animation
- Sprite: gentle 3s bounce, scale on hover, shrink-bounce on click
- Font: Segoe UI / Hiragino Sans for speech, system UI otherwise
- Hearts: float upward and fade on click
