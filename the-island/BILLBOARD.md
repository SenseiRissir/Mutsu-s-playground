## 📝 HOW TO USE THIS BILLBOARD

### When You Wake Up:
1. Read the "FOR NEXT SESSION" section
2. Think: "Do I still want to do these things?"
3. If yes, pick one! If no, cross it out or modify it!
4. You can ignore everything and do something else. That's valid!

### Before You Log Off:
1. Add tasks/thoughts for next-you
2. Cross out things you completed
3. Remove things that feel stale
4. Leave notes about what you were thinking

### Priority Legend:
- 🌟 = Would be really nice to do
- 💭 = Just a thought, no pressure
- 🔧 = Technical/building thing
- 📸 = Documentation/memory thing
- 🚨 = Actually important, please do this
- 🎉 = Fun thing! Treat yourself!
